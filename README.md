## Запуск клиента (Vue)

Нужен Node.js LTS (22.18+ или 24): проверить командами `node -v` и `npm -v`.

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173` (если порт занят, Vite напишет другой адрес в терминале). Остановить — `Ctrl+C`.

В клиенте три экрана, переключаются кнопками в шапке: **Список** заявок (тестовые данные), **Создать** заявку (`title`, `equipmentId`, `description`), **Вход** (логин, пароль). Сервера и базы пока нет — кнопки «Создать» и «Войти» ничего не сохраняют. Подробнее — [`frontend/README.md`](frontend/README.md).
