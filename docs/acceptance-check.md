# Проверка трёх критериев приёмки (ЛР12)

Критерии — из [`lab-01-requirements.md`](lab-01-requirements.md), раздел «Обязательные до курсовой». Проверка идёт на развёрнутом стенде по README (Vue :5173 → API :5000 → PostgreSQL `toir_workshop`), без ручных правок в базе. Пароль учебных учёток — `Toir-2026!`.

Проверяется **одна** заявка: её `id` записывается на шаге 1.2 и дальше ищется везде.

Где смотреть: **Экран** — интерфейс Vue; **Запрос** — F12 → Network (адреса на порт 5000), Swagger или Postman; **SQL** — pgAdmin или `psql -U postgres -d toir_workshop`.

## Критерий 1. Создать объект

Дано: мастер участка вошёл.

| Шаг | Действие | Что ждём | Где смотреть |
|-----|----------|----------|--------------|
| 1.1 | Вход `ivanov` | Список заявок, в шапке «Иванов А. П. · мастер участка», есть кнопка «Создать» | **Экран**; **Запрос**: `POST /api/auth/login` → 200 |
| 1.2 | «Создать» → заголовок 5–80 символов, оборудование из списка, описание 10–500 → «Создать» | Возврат в список, сверху строка `ЗР-ГГГГ-NNNN`, `id N`, статус «Новая», исполнитель «—». **Записать N** | **Экран** |
| 1.3 | — | `POST /api/work-orders` → **201**; в Request только `title`, `equipmentId`, `description`; в Response тот же `id = N`, `number`, `"status":"New"`, `"assigneeUserId":null` | **Запрос** (Network → Response) |
| 1.4 | — | Одна строка: `status = New`, `assignee_user_id` пусто, `created_by_user_id = 1` | **SQL**: `SELECT id, number, title, status, assignee_user_id, created_by_user_id FROM work_orders WHERE id = N;` |
| 1.5 | Короткий заголовок «Шум» | Заявка не создаётся, сообщение у поля «Заголовок» | **Экран** |
| 1.6 | Вход `petrov`: кнопки «Создать» нет; прямой `POST /api/work-orders` с его токеном | **403** | **Экран**; **Запрос** (Swagger/Postman «00 POST слесарем») |

Результат 07.11.2026: **да** — `id = 1`, `ЗР-2026-0001` (см. отчёт ЛР12).

## Критерий 2. Назначить исполнителя

Дано: механик цеха вошёл, заявка `N` в статусе `New`.

| Шаг | Действие | Что ждём | Где смотреть |
|-----|----------|----------|--------------|
| 2.1 | «Выйти», вход `kuznetsov` | В строке заявки `N` — список слесарей, кнопки «Назначить» и «Отменить» | **Экран**; **Запрос**: `GET /api/users?role=Fitter` → 200 |
| 2.2 | Выбрать «Петров С. И.» → «Назначить» | Исполнитель «Петров С. И.», статус **остаётся «Новая»**, сообщение «назначен исполнитель» | **Экран** |
| 2.3 | — | `PATCH /api/work-orders/N/assignee`, тело `{"assigneeUserId":5}` → **200**; в ответе `"status":"New"`, `"assigneeUserId":5` | **Запрос** |
| 2.4 | — | `assignee_user_id = 5`, `status = New` | **SQL**: `SELECT id, status, assignee_user_id FROM work_orders WHERE id = N;` |
| 2.5 | Вход `ivanov` (мастер): кнопки «Назначить» нет; прямой `PATCH …/N/assignee` с его токеном | **403** (ФТ-9) | **Экран**; **Запрос** (Postman «09a») |

Результат 07.11.2026: **да**.

## Критерий 3. Исполнитель перевёл в работу

Дано: назначенный слесарь-ремонтник вошёл.

| Шаг | Действие | Что ждём | Где смотреть |
|-----|----------|----------|--------------|
| 3.1 | «Выйти», вход `sidorov` (другой слесарь) | У заявки `N` нет кнопок | **Экран** |
| 3.2 | Вход в Swagger за `sidorov` → Authorize → `PATCH /api/work-orders/N/status` `{"status":"InProgress"}` | **403** «Нет прав на изменение этой заявки: она назначена другому слесарю», статус не изменился | **Запрос**; **SQL**: `status` всё ещё `New` |
| 3.3 | «Выйти», вход `petrov`, «Мои заявки» → «В ремонт» | Статус «В ремонте», появилась кнопка «Выполнена» | **Экран** |
| 3.4 | — | `PATCH /api/work-orders/N/status`, тело `{"status":"InProgress"}` → **200** | **Запрос** |
| 3.5 | — | `status = InProgress`, `assignee_user_id = 5`, `updated_at` позже `created_at` | **SQL**: `SELECT id, number, status, assignee_user_id, created_at, updated_at FROM work_orders WHERE id = N;` |
| 3.6 | Остановить API (`Ctrl+C`), снова `dotnet run`, обновить страницу | Заявка `N` на месте, «В ремонте», исполнитель Петров | **Экран**; **Запрос**: `GET /api/work-orders` → 200 |

Результат 07.11.2026: **да**.
