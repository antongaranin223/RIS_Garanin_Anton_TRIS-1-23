# Матрица ролей ТОиР-Цех (ЛР11)

Роли — из ЛР1 ([`lab-01-requirements.md`](lab-01-requirements.md), раздел «Роли»), пути — из контракта ЛР2 ([`api-contract.md`](api-contract.md)).
Права проверяет **сервер** (НФТ-2). Клиент только прячет лишние кнопки, но запрещает сервер: прямой запрос в Swagger получит тот же 401/403.

Способ входа — **учебный JWT** в заголовке `Authorization: Bearer <токен>` (cookie не используются).

## Матрица «роль × действие»

| Действие | Мастер участка | Механик цеха | Слесарь-ремонтник | Начальник цеха | Гость (не вошёл) |
|----------|----------------|--------------|-------------------|----------------|------------------|
| `POST /api/auth/login` вход | да → 200 | да → 200 | да → 200 | да → 200 | неверный пароль → 401 |
| `GET /api/work-orders`, `GET /api/work-orders/{id}` | да → 200 | да → 200 | да → 200 | да → 200 | нет → 401 |
| `POST /api/work-orders` создать | да → 201 | да → 201 | нет → **403** | нет → **403** | нет → **401** |
| `PATCH …/assignee` назначить слесаря | нет → **403** | да → 200 | нет → **403** | нет → **403** | нет → 401 |
| `PATCH …/status` `New → InProgress` **своей** заявки | нет → 403 | нет → 403 | да → 200 | нет → 403 | нет → 401 |
| `PATCH …/status` `InProgress → Closed` **своей** заявки | нет → 403 | нет → 403 | да → 200 | нет → 403 | нет → 401 |
| `PATCH …/status` заявки, назначенной **другому** слесарю | нет → 403 | нет → 403 | нет → **403** (ФТ-8) | нет → 403 | нет → 401 |
| `PATCH …/status` `New → Cancelled` | только **своей** (автор) → 200, чужой → 403 | да → 200 | нет → 403 | нет → 403 | нет → 401 |

`409` — не про права, а про жизненный цикл: переход, которого нет в таблице статусов (`Closed → InProgress`, `New → Closed`), назначение не в `New`, «в ремонт» без исполнителя. Его получает и тот, у кого права есть. Порядок проверки `PATCH …/status`: сначала «бывает ли такой переход вообще» (409), потом «можно ли его делать тебе» (403).

## Где это в коде

| Проверка | Где |
|----------|-----|
| Нет токена, токен испорчен или истёк → 401 | `[Authorize]` на `WorkOrdersController` + `AddJwtBearer` в `backend/Program.cs` (событие `OnChallenge`) |
| Роль не может создавать / назначать → 403 | `[Authorize(Roles = "Foreman,Mechanic")]` на `Create`, `[Authorize(Roles = "Mechanic")]` на `Assign` (событие `OnForbidden`); то же повторено в `EfWorkOrderService` |
| Чужая заявка (чужой `id` в адресе) → 403 | `EfWorkOrderService.CheckTransition`: `w.AssigneeUserId != user.Id` для слесаря, `w.CreatedByUserId == user.Id` для отмены мастером |
| Кто выполняет действие | только `User.GetUserId()` — утверждение `sub` из проверенного токена (`backend/Auth/AuthClaims.cs`); id из тела или заголовка не принимается |
| Пароль | `PasswordHasher<AppUser>` (`AuthController.Login`), хэши в seed — `backend/Data/ReferenceData.cs` |
